📊 Sumber Data Google Sheets

Cara Kerja
Dashboard fetch data dari Google Sheets setiap 5 menit otomatis. Data diambil via Google Visualization API (gratis, tanpa API key). Spreadsheet harus di-share ke "Anyone with the link → Viewer".

Sheet yang Digunakan

SheetFungsiStatus
MASTER DATAData Perumahan / semua transaksi✅ Aktif
MASTER DATA EKMAData Apartemen (nanti)⏸️ Nonaktif

Cara Aktifkan Sheet Apartemen (saat sudah siap)

Buka assets/js/config.js, ubah baris ini:

assets/js/config.js — baris 7
// Sebelum (nonaktif):
SHEET_APARTEMEN: '',

// Sesudah (aktifkan):
SHEET_APARTEMEN: 'MASTER DATA EKMA',

Rumus Bobot Nilai

Bobot = (Trx/Day Score × 40%) + (% CB Trx × 40%) + (% CB Buyers × 20%)

Trx/Day Score = min(100, Trx/Day ÷ 10 × 100)
→ Target 10 trx/hari = score 100
→ 5 trx/hari = score 50
→ >10 trx/hari = tetap 100 (maksimal)

Contoh:
  Trx/Day = 8    → Score A = 80
  % CB Trx = 65% → Score B = 65
  % CB Buyers = 70% → Score C = 70
  Bobot = (80×0.4) + (65×0.4) + (70×0.2) = 32 + 26 + 14 = 72

Mengubah Rumus Bobot Nilai

assets/js/data.js — cari "calcBobot" atau "scoreA scoreB scoreC"
// Rumus saat ini:
const scoreA = Math.min(100, Math.round(trxPerDay/10*100)); // 40%
const scoreB = pctCbTrx;   // 40%
const scoreC = ...;        // 20%
const bobot  = Math.round(scoreA*0.4 + scoreB*0.4 + scoreC*0.2);

// Untuk ubah bobot, ganti angka 0.4, 0.4, 0.2
// Total harus = 1.0 (100%)

Mengubah Target Trx/Day

assets/js/data.js — cari "trxPerDay/10"
// Target sekarang = 10 trx/hari
const scoreA = Math.min(100, Math.round(trxPerDay/10*100));

// Ganti 10 dengan angka target baru, misal 15:
const scoreA = Math.min(100, Math.round(trxPerDay/15*100));

${buildSection('cNama','🆕 Nama Panel',
  buildTable(trend,latest,

🔍 Edit Filter & Dropdown

Menambah Filter Baru

Langkah 1 — Tambah dropdown di HTML (misal di store.html)
<select class="fselect" id="fNamaFilter" onchange="applyFilters()">
  <option value="">Semua Nama Filter</option>
</select>
Langkah 2 — Isi pilihan di populateFilters() dalam data.js
fillSel('fNamaFilter', unique(COL.KOLOM_TERKAIT), 'Semua Nama Filter');
Langkah 3 — Tambah kondisi filter di applyFilters() dalam data.js
if (v('fNamaFilter') && r[COL.KOLOM_TERKAIT] !== v('fNamaFilter')) return false;

Data masih Demo ModeDEMO_MODE: true di config.jsUbah ke false, simpan, deploy ulang
