🤖
Point Chatbot Performance
Halaman: Summary

Section Buyers

// Chatbot Buyers = unique AG yang punya transaksi via chatbot Chatbot Buyers = jumlah unik Kolom AG dimana Kolom K = "NEW REG" atau "REPEAT" % LM Chatbot Buyers = (LM Chatbot Buyers ÷ Chatbot Buyers) × 100 // LM Chatbot Buyers = unique AG yang beli LM via chatbot // Ditampilkan: angka Chatbot Buyers + % dari total buyers + % LM dari chatbot

Section Transaction

Chatbot Trx = jumlah baris dimana Kolom K = "NEW REG" atau "REPEAT" % CB dari Total = (Chatbot Trx ÷ Total Trx) × 100 LM Chatbot Trx = jumlah baris dimana K=chatbot DAN N=LE MINERALE % LM dari CB Trx = (LM CB Trx ÷ Chatbot Trx) × 100

Section Gallon via Chatbot

Gallon Sold (Total) = jumlah semua Kolom P (Qty) Gallon via Chatbot = jumlah Kolom P dimana Kolom K = chatbot % CB Galon = (CB Galon ÷ Total Galon) × 100 LM Galon via CB = jumlah Kolom P dimana K=chatbot DAN N=LE MINERALE % LM Galon CB = (LM CB Galon ÷ CB Galon) × 100

Chatbot Usership
Halaman: Summary

% Repeat Buyers

Repeat Buyers = jumlah unik Kolom AG dimana Kolom K = "REPEAT" (exact) % Repeat = (Repeat Buyers ÷ Chatbot Buyers) × 100 // Bukan NEW REG, harus tepat "REPEAT"

Lapsers

// Lapsers = customer yang pernah chatbot tapi terakhir transaksinya MANUAL Lapsers = dari Chatbot Buyers, filter yang transaksi TERAKHIR-nya = "MANUAL" // Cara: ambil status transaksi terbaru per AG, kalau MANUAL = lapser % Lapsers = (Lapsers ÷ Chatbot Buyers) × 100

Switching to LM

// Switch = customer yang pernah beli produk LAIN (non-LM) tapi juga pernah beli LM Switching to LM = unique AG yang punya history LE MINERALE DAN produk lain % Switch = (Switching ÷ Total Buyers) × 100

Total Performance & Chatbot Performance (Donut Chart)
Halaman: Summary

Unit Share (Total)

% LM Unit Share = (Total Galon LM ÷ Total Galon Semua) × 100 % AQ Unit Share = (Total Galon AQ ÷ Total Galon Semua) × 100 % OT Unit Share = (Total Galon Other ÷ Total Galon Semua) × 100 // Galon = jumlah Kolom P (Qty)

Buyers Share (Total)

% LM Buyers = (Unique AG beli LM ÷ Total Unique AG) × 100 % AQ Buyers = (Unique AG beli AQ ÷ Total Unique AG) × 100 % OT Buyers = sisanya // 1 AG bisa masuk ke LM dan AQ sekaligus jika pernah beli keduanya

Transaction Share (Total)

% LM Trx = (Jumlah baris N=LM ÷ Total baris) × 100 % AQ Trx = (Jumlah baris N=AQ ÷ Total baris) × 100 % OT Trx = sisanya

Chatbot Performance (semua sama tapi difilter K=chatbot)

Unit Share (Chatbot) = dari transaksi chatbot saja Buyers Share (Chatbot) = unique AG yang pernah chatbot Trx Share (Chatbot) = dari transaksi chatbot saja

⚖️ Rumus Bobot Nilai

⚖️
Bobot Nilai — Dipakai di Store dan MD&TL
Berlaku di: store.html, md-tl.html
// Bobot = skor gabungan 3 komponen // Range: 0 - 100 Score A = min(100, (Trx/Day ÷ 10) × 100) // Komponen: Total Transaksi per Hari // Target: 10 trx/hari = score 100. Lebih dari 10 = tetap 100 (cap) // Contoh: 8 trx/hari = score 80; 5 trx/hari = score 50 Score B = % Chatbot Trx // Komponen: % transaksi via chatbot dari total transaksi // Contoh: 65% chatbot = score 65 Score C = % CB Buyers // Komponen: % buyer yang pernah chatbot dari total buyer // Contoh: 70% buyer pernah chatbot = score 70 Bobot = (Score A × 0.4) + (Score B × 0.4) + (Score C × 0.2) // Bobot = Total Trx 40% + % CB Trx 40% + % CB Buyer 20% // Contoh kalkulasi: // Trx/Day = 8 → Score A = 80 // CB Trx = 65% → Score B = 65 // CB Buyer = 70% → Score C = 70 Bobot = (80 × 0.4) + (65 × 0.4) + (70 × 0.2) = 32 + 26 + 14 = 72
Cara mengubah bobot: Buka assets/js/data.js → cari scoreA*0.4+scoreB*0.4+scoreC*0.2 → ubah angka bobotnya. Total harus = 1.0

// MS = Market Share = porsi galon Le Minerale dari total galon toko % MS After = (Total Galon LM terjual di outlet ÷ Total Galon SEMUA produk di outlet) × 100 // Dihitung dari data transaksi spreadsheet secara LIVE/REALTIME // Contoh: LM jual 500 galon, total semua produk 1000 galon = MS After 50% % MS Before = Data yang DIINPUT MANUAL oleh admin // Dikelola di halaman "Data MS Before" (menu user → Data MS Before) // Disimpan di localStorage browser — harus diinput sekali per outlet % Growth = MS After − MS Before // positif = toko semakin dominan, negatif = menurun KPI = Growth ÷ 100 // Simplified KPI score
